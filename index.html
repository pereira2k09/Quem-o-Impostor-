Como jogar

1. Configure

Coloque os nomes, escolha os impostores e selecione palavras gerais ou um tema.

2. Passe o celular

Cada jogador verá seu nome. Ele deve segurar o botão para descobrir a palavra ou se é o impostor.

3. Não deixe ninguém ver

Ao soltar o botão, a informação desaparece. Passe o dispositivo para o próximo jogador.

4. Sorteio

Quando todos terminarem, o site sorteia quem começa. Impostores nunca entram nesse sorteio.

5. Jogue presencialmente

O jogador sorteado começa dando uma dica. Depois, conversem e tentem descobrir o impostor.
